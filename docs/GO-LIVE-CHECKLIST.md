# 오픈 전 점검 체크리스트

팀원들에게 열기 **전에** 한 바퀴 돌려보는 목록입니다.
Firestore 규칙을 배포하기 전에는 `courses` / `lessonProgress` / `proctorSessions` 가 막혀 있어서
**LMS 기능이 실제 환경에서 한 번도 동작한 적이 없습니다.** 그래서 이 검증이 필요합니다.

---

## 0. 설정 (한 번만)

- [ ] Firebase 콘솔 → Authentication → Settings → **승인된 도메인**에 배포 도메인 추가
      (`test-site-79ed.onrender.com`)
- [ ] Google AI Studio → Gemini API 키 → **사용량 제한(quota)** 설정
      (키가 번들에 노출되므로, 남이 써도 피해가 제한되도록)
- [ ] 팀원 **이메일을 명부에 미리 입력** — 관리자 → 팀원 관리
      ⚠️ 팀원이 **첫 로그인하기 전에** 넣어야 합니다. 이후에 넣으면 계정 주소가 안 바뀌어
      비밀번호 재설정 메일을 받을 수 없습니다.

## 1. 관리자 계정

- [ ] 관리자 학번으로 로그인 → **관리자 대시보드 입장** 버튼이 보임
- [ ] **퀴즈 생성** 탭 → 문제 만들고 **저장** → "저장 성공" 후 결과 탭 목록에 나타남
- [ ] **코스** 탭 → 새 코스 → 모듈 추가 → 영상 레슨(YouTube 링크) + 퀴즈 레슨 → **저장**
- [ ] **팀원 관리** → 테스트용 학번 하나 등록 (이메일 포함)

## 2. 학생 계정 (테스트 학번으로)

- [ ] 로그아웃 → 테스트 학번 입력 → **비밀번호 설정** 화면이 뜸 → 비밀번호 생성 → 입장
- [ ] 홈에 **강의 코스** 카드가 보임
- [ ] 영상 재생 → **진행률이 올라감**
- [ ] 진행바를 앞으로 드래그 → **되돌려지고 "건너뛸 수 없습니다" 안내**
- [ ] 배속 2x 시도 → **1배속으로 리셋**
- [ ] 다른 탭으로 이동 → **영상이 자동 일시정지**
- [ ] 퀴즈 응시 → 제출 → 채점 결과가 나오고 **성적 히스토리**에 기록됨
- [ ] 복수정답 문항이 있다면 → **두 개 이상 동시에 선택됨**

## 3. 관리자에서 결과 확인

- [ ] **결과** 탭 → 테스트 학생의 응시 기록이 보임
- [ ] **이수현황** 탭 → 코스별 진행률이 반영됨
- [ ] **부정행위** 탭 → 응시 세션과 이벤트 타임라인이 쌓여 있음
- [ ] **통계** 탭 → 정답률/리더보드가 계산됨

## 4. 마무리

- [ ] 브라우저 콘솔(F12)에 **`Missing or insufficient permissions`** 가 없는지
- [ ] 테스트용 학번/퀴즈/코스 정리
- [ ] 팀원 안내: *"학번 입력 후 비밀번호를 만들어주세요(6자 이상). 처음 로그인하면 설정 화면이 나옵니다."*

---

## 막혔을 때

**`Missing or insufficient permissions`** → 규칙 문제입니다.
어느 화면에서 무슨 동작을 할 때 났는지 확인하고 `firestore.rules` 의 해당 컬렉션 블록을 보세요.
규칙에 없는 컬렉션은 **기본이 거부**입니다.

**관리자 버튼이 안 보임** → `admins/{내 UID}` 문서가 있는지, 문서에 **필드가 1개 이상** 있는지
(필드가 0개면 Firestore 가 "존재하지 않는 문서"로 취급합니다). 확인 후 재로그인.

**로그인이 튕김** → `students/{학번}` 문서에 `uid` 필드가 있는지 확인하세요.
